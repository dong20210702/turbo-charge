# v69

### Changelog

1.修复运行期间内核节点短暂不可用就退出进程的问题（进程消失后快充彻底失效，只能重启手机）

2.修复温度传感器路径无法回传主函数的问题（一进入温度控制就会因找不到文件而退出）

3.修复“伪”旁路供电配置文件修改时间判断错误，以及由此产生的每轮循环内存泄漏

4.修复写值函数未检查stat返回值、栈上缓冲区长度取自未初始化值的问题

5.修复目录扫描和文件列表写死固定长度上限导致的越界隐患

6.修复温度换算在低于10℃和负温度时算错的问题

7.修复获取前台应用的子线程可能被重复创建、被取消后标志位无法复位的问题

8.修复配置文件读取线程在读取失败时空转烧CPU、inotify漏报后不再重载配置的问题

9.修复配置值超过2147483647时的未定义行为，以及电流配置过小导致内核停止充电的问题

10.修复互斥锁未按标准初始化、未在未充电分支读取电量等问题

11.启动脚本改为单实例+守护重启，程序意外退出会自动拉起，不再出现两个实例互相抢写节点的情况

12.周期性复查只在启动时写一次的内核参数，被系统改回后自动补写，避免拔插充电器后失去快充
